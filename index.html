Offline-First Multi-Archive HTTP (HAR) Analyzer & JSON Table Unroller

HarLens is a zero-dependency, privacy-first web utility for developers, security researchers, and QA engineers to inspect, search, and visualize HTTP archive (.har) network logs without uploading sensitive traffic to external servers.

⚡ Multi-Archive Merging

Load and cross-correlate multiple session archives, microservice logs, or paged network calls into a unified interactive timeline.

📊 JSON Table Unroller & Duplicate Merging

Transform deeply nested JSON payloads and API responses into flat interactive tables with live column exclusion, drag-resizing, and smart duplicate collapsing by ID.

📥 Zero-Dependency Excel XLSX Export

Generate compliant Microsoft Excel (.xlsx SpreadsheetML) workbooks and CSV files entirely client-side without external cloud dependencies.

🔍 Deep Arabic & Unicode Normalization

Perform multi-token search across URLs, headers, queries, and response bodies with Arabic diacritic stripping and Alef/Taa/Yaa unification.

🌐 Native Webpage Replay & Previews

Safely replay captured HTML web pages in an isolated sandbox with local virtual asset rewriting, PDF previews, and media playback.

🌳 Hierarchical Route Tree Diagram

Explore visual domain-and-endpoint topologies to diagnose API routes, error distributions, and latency bottlenecks.
